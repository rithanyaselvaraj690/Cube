Unity 3D Cube Interaction Project

Description

This project is a simple Unity 3D demonstration created to explore basic C# scripting and GameObject behavior. It contains three cubes, each performing a unique action: mouse-click interaction, automatic color transition, and continuous rotation. The project helps in understanding how scripts can control objects and create interactive effects in Unity.

Features

- Cube 1 – Click Interaction: Changes its color whenever the user clicks on the cube.
- Cube 2 – Dynamic Color Effect: Automatically changes between different colors.
- Cube 3 – Rotation Effect: Rotates continuously while the game is running.

Technologies Used

- Unity 3D
- C#
- Unity Editor

Working

Each cube has a separate C# script attached to control its behavior. User input is detected for the interactive cube, while the other cubes perform their actions automatically during runtime.

How to Run

1. Open the project using Unity Hub.
2. Load the required Unity scene.
3. Press the Play button.
4. Click the first cube to see the interaction.
5. Observe the color-changing and rotating effects of the other cubes.

Result

The project successfully demonstrates basic Unity scripting, mouse interaction, color effects, and object rotation using three different 3D cubes.
